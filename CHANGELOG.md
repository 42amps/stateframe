# Changelog

## 0.1.0

- Initial experimental release of Stateframe.
- Added file-first `task.ledger.json` workflow.
- Added CLI commands for demo, init, status, add, lock, unlock, handoff, extract, commit-candidates, and validate.
- Added portable handoff generation as Markdown or JSON.
- Added JSON Schema, protocol notes, examples, and packageable CLI build output.
